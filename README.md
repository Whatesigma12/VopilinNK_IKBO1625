# Практическая работа №1. Конфигурационное управление (Вариант 8)

## 1. Общее описание
Данный проект представляет собой эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом (GUI) на базе библиотеки `tkinter`. Эмулятор поддерживает работу с виртуальной файловой системой (VFS), загружаемой из пользовательской директории непосредственно в оперативную память без модификации файлов на диске.

## 2. Описание всех функций и настроек

### Параметры командной строки:
- `--vfs <путь>` — путь к физическому расположению директории VFS на диске (по умолчанию `./vfs_data/minimal`).
- `--script <путь>` — путь к стартовому скрипту для автоматического выполнения команд при запуске. При исполнении скрипта ошибочные строки пропускаются, а на экране имитируется диалог с пользователем.

### Поддерживаемые команды:
- `ls [-l] [путь]` — вывод списка файлов и папок в текущей или указанной директории. Флаг `-l` выводит права доступа.
- `cd [путь]` — смена текущей рабочей директории в рамках VFS.
- `date` — вывод текущей системной даты и времени.
- `head [-n ЧИСЛО] <файл>` — вывод первых строк файла (по умолчанию 10 строк).
- `touch <файл>` — создание нового пустого файла в памяти VFS.
- `chmod <режим> <путь>` — изменение прав доступа (например, `755`, `644`, `777`) к файлу или папке в памяти VFS.
- `exit` — закрытие окна эмулятора и завершение работы.

## 3. Описание команд для сборки проекта и запуска тестов

Проект написан на языке Python 3 и использует только стандартную библиотеку. Дополнительная сборка не требуется.

### Запуск приложения:
```bash
sh run.sh
```

### Запуск модульных тестов:
```bash
python3 -m unittest discover -s tests
```

### Запуск тестовых скриптов ОС:
```bash
sh scripts/test_stage2.sh
sh scripts/test_stage3.sh
```

## 4. Примеры использования

Запуск эмулятора с многофайловой VFS и стартовым скриптом 5-го этапа:
```bash
python3 src/main.py --vfs ./vfs_data/multi --script ./scripts/start_stage5.txt
```

Пример интерактивной сессии в GUI:
```text
/$ ls -l
644 file1.txt
644 file2.txt
644 notes.txt
/$ touch report.txt
/$ chmod 755 report.txt
/$ ls -l
644 file1.txt
644 file2.txt
644 notes.txt
755 report.txt
/$ head -n 2 file1.txt
Line 1
Line 2
/$ date
2026-10-27 20:00:00
/$ exit
```
