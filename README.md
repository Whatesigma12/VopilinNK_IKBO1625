# Практическая работа №1. Конфигурационное управление (Вариант 8)

## 1. Общее описание

Проект представляет собой эмулятор командной строки UNIX-подобной ОС
с графическим интерфейсом на базе библиотеки `tkinter`. Виртуальная
файловая система (VFS) загружается из указанной директории в память.
Команды `touch` и `chmod` изменяют только VFS, а не файлы на диске.

## 2. Описание функций и настроек

### Параметры командной строки

- `--vfs <путь>` — директория-источник VFS.
  По умолчанию: `./vfs_data/minimal`.
- `--script <путь>` — файл со стартовыми командами.
  Команды выполняются по порядку; ошибки отображаются в окне,
  после чего обработка скрипта продолжается.

### Поддерживаемые команды

- `ls [-a] [-l] [путь]` — список файлов и папок.
  Флаг `-l` выводит права доступа, `-a` включает скрытые элементы.
  Допускаются объединённые флаги `-la` и `-al`.
- `cd [путь]` — смена текущей директории VFS.
- `date` — вывод системных даты и времени; аргументы не принимаются.
- `head [-n ЧИСЛО] <файл>` — вывод первых строк файла.
  По умолчанию выводится 10 строк; число после `-n` должно быть
  положительным.
- `touch <файл>` — создание пустого файла в памяти VFS.
- `chmod <режим> <путь>` — изменение прав доступа в памяти VFS.
  Режим задаётся тремя восьмеричными цифрами, например `755` или `644`.
- `exit` — закрытие окна; команда не принимает аргументов.

## 3. Запуск и тестирование

Проект написан на Python 3 и использует стандартную библиотеку.
Дополнительная сборка не требуется.

Запуск приложения:

```bash
sh run.sh
```

Запуск модульных тестов:

```bash
python3 -m unittest discover -s tests
```

Запуск сценариев проверки конфигурации и структуры VFS:

```bash
sh scripts/test_stage2.sh
sh scripts/test_stage3.sh
```

Запуск с многофайловой VFS и сценарием пятого этапа:

```bash
python3 src/main.py --vfs ./vfs_data/multi \
  --script ./scripts/start_stage5.txt
```

## 4. Примеры использования

Пример команд в окне эмулятора:

```text
/$ ls -la
/$ head -n 2 file1.txt
Line 1
Line 2
/$ touch report.txt
/$ chmod 755 report.txt
/$ ls -l
644 file1.txt
644 file2.txt
644 notes.txt
755 report.txt
/$ date
2026-10-27 20:00:00
/$ exit
```

Ошибочные аргументы также обрабатываются. Например, `head -n 0 file1.txt`
выводит сообщение о том, что количество строк должно быть положительным.
