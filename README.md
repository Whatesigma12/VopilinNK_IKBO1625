# Конфигурационное управление

Репозиторий практических работ по дисциплине «Конфигурационное управление».

## Практические работы

- `1_practice` — эмулятор командной оболочки с виртуальной файловой системой.
- `2_practice` — анализатор и визуализатор графа зависимостей npm-пакетов, вариант 8.

Подробное описание, команды запуска, тесты и примеры находятся в README.md каждой практической работы.

## Запуск тестов

Первая практическая работа:

```bash
cd 1_practice
python -m unittest discover -s tests -v
```

Вторая практическая работа:

```bash
cd 2_practice
python -m unittest discover -s tests -v
```

GitHub Actions запускает оба набора тестов автоматически.
