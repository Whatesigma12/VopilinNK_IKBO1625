## Общее описание

Проект представляет собой эмулятор командной строки
UNIX-подобной ОС с графическим интерфейсом на базе стандартной
библиотеки `tkinter`.

Виртуальная файловая система (VFS) загружается из указанной
директории в память. Команды работают с объектами VFS.
`touch` и `chmod` изменяют только состояние в памяти и не
изменяют исходные файлы на диске.

## Настройки запуска

### `--vfs <путь>`

Указывает директорию, которая загружается в память как VFS.

Значение по умолчанию:

```text
./vfs_data/minimal
```

### `--script <путь>`

Указывает стартовый текстовый файл с командами. Команды
выполняются по порядку после запуска интерфейса.

Пример:

```bash
python3 src/main.py --vfs ./vfs_data/multi \
  --script ./scripts/start_stage5.txt
```

## Поддерживаемые команды

| Команда | Назначение |
| --- | --- |
| `ls [-a] [-l] [путь]` | Показывает содержимое директории |
| `cd [путь]` | Меняет текущую директорию |
| `date` | Показывает текущие дату и время |
| `head [-n ЧИСЛО] <файл>` | Показывает первые строки файла |
| `touch <файл>` | Создаёт пустой файл в памяти VFS |
| `chmod <режим> <путь>` | Меняет права объекта в памяти VFS |
| `exit` | Закрывает окно эмулятора |

Для `ls` поддерживаются `-l`, `-a`, `-la` и `-al`.

Для `head` число строк должно быть положительным. Если
`-n` не задан, используется 10 строк.

Режим `chmod` задаётся тремя восьмеричными цифрами, например
`755` или `644`.

## Все функции, классы и настройки

### `commands.py`

| Элемент | Назначение |
| --- | --- |
| `_split_ls_args(args)` | Разделяет аргументы `ls` на флаги и пути |
| `_validate_ls_args(...)` | Проверяет допустимость аргументов `ls` |
| `_format_file(...)` | Формирует строку для одного файла |
| `exec_ls(vfs, args)` | Выполняет команду `ls` |
| `_format_dir_children(...)` | Формирует вывод содержимого директории |
| `_format_child(...)` | Формирует строку дочернего элемента |
| `exec_cd(vfs, args)` | Выполняет смену текущей директории |
| `exec_date(args)` | Возвращает системные дату и время |
| `exec_head(vfs, args)` | Возвращает первые строки файла |
| `_parse_head_args(args)` | Разбирает аргументы `head` |
| `_parse_head_count(...)` | Проверяет положительное число строк |
| `exec_touch(vfs, args)` | Создаёт файл в памяти VFS |
| `exec_chmod(vfs, args)` | Изменяет права объекта VFS |

Константы `EMPTY_COUNT`, `ONE_ARG`, `TWO_ARGS`,
`THREE_ARGS`, `DEFAULT_HEAD_LINES`, `MODE_LEN`,
`OCTAL_CHARS` и `LS_FLAGS` задают правила команд и
устраняют магические числовые литералы в проверках.

### `vfs.py`

| Элемент | Назначение |
| --- | --- |
| `VFSNode.__init__(...)` | Создаёт узел файла или директории |
| `VFS.__init__()` | Создаёт пустую виртуальную файловую систему |
| `VFS.load_from_dir(...)` | Загружает физическую директорию в память |
| `VFS._read_dir_recursive(...)` | Рекурсивно читает дерево каталогов |
| `VFS._read_file_node(...)` | Читает содержимое файла |
| `VFS.resolve_path(path)` | Преобразует путь в абсолютный путь VFS |
| `VFS.get_node(path)` | Возвращает узел по пути |
| `VFS.get_parent_and_name(path)` | Возвращает родителя и имя элемента |

Константы `DEFAULT_DIR_MODE`, `DEFAULT_FILE_MODE` и
`ROOT_PATH` задают права по умолчанию и корневой путь.

### `main.py`

| Элемент | Назначение |
| --- | --- |
| `parse_args()` | Разбирает `--vfs` и `--script` |
| `ShellGUI.__init__(...)` | Инициализирует GUI, VFS и стартовый скрипт |
| `ShellGUI.init_vfs()` | Загружает VFS и устанавливает заголовок |
| `ShellGUI.create_widgets()` | Создаёт поле вывода и поле ввода |
| `ShellGUI.print_debug_info()` | Показывает параметры запуска |
| `ShellGUI.write_output(text)` | Записывает текст в окно |
| `ShellGUI.run_script(path)` | Выполняет стартовый сценарий |
| `ShellGUI.on_enter(...)` | Обрабатывает Enter |
| `ShellGUI.process_line(line)` | Разбирает введённую строку |
| `ShellGUI.dispatch(cmd, args)` | Выбирает обработчик команды |
| `ShellGUI.cmd_exit(args)` | Проверяет аргументы и закрывает окно |
| `main()` | Создаёт окно и запускает цикл GUI |

Константа `MIN_ARGS` используется при проверке пустого ввода
и аргументов команды `exit`.

## Запуск

Из каталога `1_practice`:

```bash
sh run.sh
```

Либо напрямую:

```bash
python3 src/main.py
```

Пример с другой VFS:

```bash
python3 src/main.py --vfs ./vfs_data/multi
```

## Пример использования

```text
/$ ls -la
/$ head -n 2 file1.txt
Line 1
Line 2
/$ touch report.txt
/$ chmod 755 report.txt
/$ ls -l
644 file1.txt
644 file2.txt
644 notes.txt
755 report.txt
/$ date
2026-10-27 20:00:00
/$ exit
```

Ошибочные аргументы обрабатываются и выводятся в интерфейсе.
Например, `head -n 0 file1.txt` сообщает, что количество
строк должно быть положительным.
